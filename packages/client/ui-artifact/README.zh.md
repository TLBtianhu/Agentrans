# @deepseek-ai/dsh-client-ui-artifact

[English](README.md) | 中文

## 概述

在产生 Artifact 的对话里阅读交互 HTML。每个 checkpoint 都能独立呈现，即使历史里只有最新修订。卡片默认留在消息流中，也可以并排成常驻结果栏、展开到整个窗口，或浮成辅助视图。你可以检查 HTML 源码，并且只在明确确认后发送 Artifact 操作。预览无法访问父应用或远程依赖。`function-plot`、`flowchart`、`particle-system`、`timeline`、`network-graph` 或 `map` SceneSpec 通过共享安全表达式解析器原生渲染，并直接确认当前分析。可选的 `style` 字段为每类原语选择视觉风格（editorial、transit-map、blueprint、math-proof-lecture 或 particles），同一份声明式规格可以呈现为数学证明、地铁图、蓝图或粒子模拟。

## 使用

在 Web 组合中将本插件与 Conversation、Chat、locale 和 Artifact Remote 服务一起挂载。Client 选项 `runtimeCommandTimeoutMs` 默认为 `10000`，限制每条程序命令的确认等待时间。Web Host 还需挂载[运行报告服务](../../artifact/artifact-runtime/README.zh.md)。

### 阅读并操作 Artifact

卡片显示 Artifact 标题和修订号。新修订会替换文档与 iframe 浏览上下文，同时保留 Conversation Node 身份。presentation 字段决定初始布局；同一个控件在四种视图间切换，并可改为显示源码。

**内联**让卡片留在消息流里，随对话滚动和换行，而不是盖住对话。**并排**把常驻结果栏固定在右边缘：对话主体让出这段宽度，正文因此变窄而不是被覆盖，结果栏从会话标题下方开始。**展开**把卡片铺满整个窗口，按 Esc 回到内联。**浮窗**在角落保留一个小型辅助视图。这些布局是 `ViewRequest` 意图，不是窗口控制权限。布局切换保留当前修订和待发送操作；卡片离开消息流时预览会重新挂载。回到内联会把 Artifact 自身那一行滚回视野。卡片同时显示当前对话或父分支来源。恢复出来的 checkpoint 不会在挂载时自动展开，只有正在进行的轮次才能请求展开呈现。

布局按会话共享，而不是每张卡片各自持有。并排第二个 Artifact 会在同一个结果栏里新增一个后台页签，不会盖住第一个；关闭当前页签会选中相邻页签，关闭最后一个会释放预留宽度。浮窗和展开视图各自同时只存在一个；同一个 Artifact 只持有一个脱离对话的表面，所以并排、浮窗、展开是在移动它，而不是再开一块。节点卸载时，它持有的表面会全部释放。分支操作会从 Artifact 的 checkpoint 开出一条独立探究分支，导出操作则把 SceneSpec 打包成自包含 HTML 动画，内嵌表达式解析器和确定性时间轴播放器；导出的页面本身也提供 WebM 下载按钮，用画布流和 MediaRecorder 把同一段重放录成视频。

iframe 操作先进入卡片内的有界未确认提案队列。点击“发送给 Agent”才会以 `wake: true` 确认第一条提案。iframe 发出消息本身不会唤醒 Agent。成功只移除已提交提案，保留后续排队操作。队列满时，卡片会明确提示，发送释放容量后才继续接受新提案。

原生场景确认、已确认的 iframe 操作和当前分析比较共用一套提交生命周期。派发前，所有者固定稳定的请求 id、Artifact id、修订、操作、完整载荷和 `wake`。发送中或结果未知待确认时，后续确认会被禁用，本地实验仍可操作。切换源码、视图和修订后，原请求仍可查看。“重试原始操作”原样重发该请求，已接受请求的重试不会重复添加输入。“放弃本地重试”只释放本地请求，不撤回 Host 可能已经接受的输入。

<a id="chat-route"></a>

根聊天和普通手动分支提供 Host 操作。subagent 聊天隐藏操作确认、观察保存与发送、比较发送、问题上下文选择，以及已保存 HTML 导出的创建与下载。本地预览、控件、源码查看、历史保存内容的浏览与恢复仍可使用，本地 WebM 录制也保留。已保留请求仍可查看，重试会被禁用。组件根据当前 Session 通道区分这些能力；注入回调在调用 Host 前再次执行同一限制。

### 隔离与输入限制

预览使用 `srcDoc` 和 `sandbox="allow-scripts"`，绝不授予 same-origin 访问。CSP 允许 inline 脚本、样式以及 data/Blob 图片与媒体，同时阻止网络连接、远程依赖、表单、嵌套 frame、插件、worker 和导航。父页面消息处理还要求当前 iframe 的 `contentWindow`；origin 字符串不是身份校验。

独立 SceneSpec 导出把模型字符串作为 JSON 数据嵌入，并通过 DOM 文本节点生成标签与读数。标签不能引入标记，也不能关闭导出的脚本元素。

操作消息必须匹配当前 Artifact id 和正整数修订号，并符合精确五字段 schema 与 JSON payload。完整序列化消息最多 16,384 个 UTF-8 字节。payload 最多嵌套 32 层、包含 2,048 个值；卡片最多保留 32 条待发送操作。

### 运行就绪与可用操作

每个实际预览打开一条绑定修订的实时报告流。原生画布仅在 2D 上下文存在、实际绘制成功后报告就绪；粒子数值失败保留错误码与有界诊断。原生本地控件不声明为 iframe 桥接命令。`getArtifactSourceCapabilities` 的源码声明描述可重算的业务操作，与实际预览、已安装服务和权限分开。

自由 HTML 通过 `window.artifactRuntime.ready({ state: () => value, commands: { step: () => advance() } })` 主动接入，只有实际提供的回调才声明支持。声明状态能力后，`reportState(value)` 发布本地状态；`error(message)` 报告有界失败。启动脚本错误和未处理的 Promise 拒绝也会报告。注入桥接在作者脚本之前运行，而 iframe load 只请求当前报告。没有就绪回调的旧文档仍可预览、明确确认操作，但不提供共享播放控件。

消息携带准确的 Artifact 身份、修订和实际运行身份，父页面同时校验当前 iframe 窗口。源码查看、重开预览和源码替换会释放旧流，并要求新身份。流丢失后清除就绪证据，并提供重开预览。报告属于实时 Client 声明，不是 Host 对像素或实验正确性的验证；上报不会产生模型输入。本地就绪与 Host 投递确认分开，报告服务不可用或权限拒绝均会显示。

HTML 共享控制只使用双方就绪运行声明的命令交集。桥接等待真实回调完成后才确认请求身份；双方都确认前保持等待。失败、部分执行和缺失确认持续可见，不自动重发。Session binding 关闭会释放报告流和待确认命令。报告与命令结果属于瞬态；只有明确确认，或模型工具已记录的查询，才进入模型历史。

### 比较组

带 `comparison: { group, role }` 的快照使用独立 Conversation Definition。Control 和 variant 保留各自的参数和修订。HTML 和非粒子当前分析比较使用绑定双方当前源码修订的报告。共享播放控制要求双方 iframe 都报告就绪并声明支持该命令。状态报告不唤醒 Agent。“比较结果”通过当前 control 修订准入双方当前分析。

原生粒子比较需要在两侧各保存一条观察，并选择“用于比较”。每次选择都以只读方式打开该观察的完整源码；“返回最新”清除该侧选择。双方必须使用相同的运行版本、时间步长和步数。“发送比较”只提交两个已保存引用，由 Host 重算数值。同一 Session 对同一有序组合只准入一次。选择在源码修订变化时保留，但属于本地状态，刷新后需要重新选择。已保存观察仍可使用。当当前 HTML 源码还具有已保存粒子观察时，明确的模式选择将实时和已保存比较路径分开。

已保存比较的结果未知时保留已提交引用，使用原身份安全重试。取消重试后可改选；取消不会撤回 Host 已准入的输入。明确拒绝会结束请求，并说明需要刷新缺失证据、创建更小实验，还是选择兼容观察。

### SceneSpec 原语

[函数绘图模板](../../../.agents/skills/artifact-design/references/function-plot.html) 展示了声明式数学 SceneSpec：两个函数、参数扫掠、视口平移/缩放、描点、导数和积分。它用本地状态支持比较，并且只在用户确认后准入 `plot.inspected`。[流程图模板](../../../.agents/skills/artifact-design/references/flowchart.html) 将同一模式用于节点、边、概念选择和路径推进，并支持确认的 `flow.inspected` 状态。[粒子系统模板](../../../.agents/skills/artifact-design/references/particle-system.html) 增加固定步长的确定性物理模拟，并支持确认的 `physics.inspected` 位置和速度。新增原语应参考这些模板，而不是为每个学科创建独立插件。内联函数图上的滚轮不会劫持对话滚动：缩放需要 Ctrl/Cmd+滚轮，普通滚轮仍然滚动消息流。

函数图在数学采样无定义的位置断开曲线。原生预览与动画导出共享数值分析；不可用读数显示为 `—`，并在确认操作和比较载荷中记为 `null`。缺失参数和非法表达式树仍然报错。数值采样不能识别所有间断点，也不提供符号求导或反常积分的证明。

原生粒子预览与导出共享固定步长的显式 Euler 计算。卡片在查看源码和切换布局时保留当前运行，导出从该步数开始重放。隐藏的预览会暂停。新修订和卡片卸载会丢弃未保存运行。数值失败会停止推进、保留最后有限状态，并提供重置操作。

在粒子卡片中为实验命名，然后选择“保存观察”。已保存观察在刷新和重新打开 Session 后仍存在。“恢复”以只读方式打开已保存源码修订，即使最新源码已是其他格式；“返回最新”回到暂停的当前运行。导出使用正在显示的源码与检查点。保存和恢复不会发送模型输入。独立卡片的“发送给 Agent”会明确准入已保存数值，同一 Session 只准入一次，已接受重试不会重复输入。待保存请求的身份在切换源码、布局和修订时保留，因此重试仍指向同一请求。比较单元格选择双方观察，不单独发送它们。

保存列表已满或源码修订已变化时，界面给出具体说明，并结束这次被拒绝的保存请求。已有观察仍可恢复和发送。保存结果未知时保留请求身份供重试；取消重试不会撤销 Host 可能已经接受的保存。

### 固定来源的 HTML 导出

独立 Scene 卡片与比较单元均提供 **导出动画**。Host 固定显示中的源码修订和粒子检查点，持久保存结果文件，再由平台文件操作服务下载。其它 Scene 类型按源码默认条件导出，不捕获局部参数滑块和选择。导出列表在刷新和源码更新后仍保留，**下载 HTML** 直接读取原始已校验文件，不再生成新结果。

无法确认生成结果时保留完整请求和原始条件，可 **重试导出**。放弃本次重试不会取消生产或删除可能已经提交的结果。恢复的 pending 记录没有确认的生产者或结果，**继续导出** 才会明确使用原始输入。失败记录保留失败原因，再次尝试需要新的导出身份。文件就绪、浏览器请求下载、实际原生保存及下载取消分别报告。这些操作均不发送模型输入。

### 围绕选定实验追问

在当前粒子实验或恢复的已保存观察上选择 **用于下次追问**，或在兼容的已保存比较上选择 **用此比较继续追问**。输入框显示可移除的问题上下文标记。正常输入并发送问题时，会在异步处理前固定实时粒子检查点或保存引用。Host 重算事实，并将完整原始条件附在同一条普通消息中。选择、播放或清除标记本身均不发送输入。

当前选择绑定所选修订与已挂载运行。源码更新或运行释放后需要重新选择或移除，不会悄悄换成另一个实验。保存引用保持原始源码。选择不跨刷新保存。此能力不附加其它原生场景状态。选择回调和捕获遵循[聊天通道限制](#chat-route)。

HTML 预览上的 **随下次追问附上程序报告** 绑定该实际预览。发送时固定最近已经收到的状态或错误，之后新消息或预览关闭不会改变该次捕获。这属于程序报告，不是即时读取程序堆，也不是 Host 重算结果。就绪预览需要声明状态读取器，并且已收到实际状态；`null`、`false`、`0` 和空字符串仍是有效值。错误无需状态即可附上。启动中、缺失状态和不支持状态报告分别解释。

HTML 选择仅保存源码与运行身份、标题和可用性。同一实例的就绪/错误变化及新收到的状态，决定之后发送时捕获什么；选择不再存一份载荷。暂时撤回的状态能力可在同实例重新上报状态后恢复。源码替换、实际重挂或报告连接中断会使选择失效，必须明确重选。已捕获的请求脱离原引用并保持不可变；即使预览改变或消失，通用发送所有者也只重试原内容。源码在首次问题准入前改变时，Host 仍会明确拒绝旧修订。选择和移除不产生模型输入。

### 带证据回流分支结论

普通手动分支的持久 assistant 结论上提供“带证据回流”，预览该结论，并允许用户选择分支可见的一个已保存观察或一对兼容观察。预览标明原始源码修订和检查点。可以使用继承的基线观察，不能使用后来的父级事实或兄弟事实。预览、选择和取消都不发送输入。

确认只向 [Artifact 分支桥接](../../artifact/artifact-branch/README.zh.md)发送父级、分支、结论序号和已保存引用。它将结论与自包含证据追加到父级，不启动模型轮次，也不替换父级 Artifact。结果未知时，原请求和预览会锁定供重试。已回流结论更换选择会产生冲突，并提供打开父级的操作。证据缺失、内容超限和服务不可用会给出具体恢复说明。自定义 GUI Host 必须挂载桥接插件才能准入。

<a id="understand-the-implementation"></a>
## 实现说明

Conversation Definition 把每条 `artifact/upsert` 都视为可独立初始化的完整 checkpoint。同一 Artifact id 的后到事件通过 `update` 替换状态，Node 保留 `context.key` 和原始 anchor。keyed `conversation.chat.node` 渲染器通过 Slot injection 获得窄 Session Remote 回调；组件不会接收 Cordis context 或 transport 对象。

修订变化会重挂载对应修订的预览，清理旧监听、浏览上下文、未确认 iframe 提案和瞬态视图状态。预览上层的 Artifact 所有者保留待保存观察的请求身份和已确认操作请求。当前比较通过同一个提交辅助函数持有独立的本地所有者。消息解析使用迭代 JSON 校验，避免递归调用栈增长。这些所有者属于组件本地状态，不是 Host 已准入的持久记录。

<a id="model-experience"></a>
## 模型体验

### Artifact 呈现与操作

#### 模型看到什么

模型看到 Host 拥有的 Artifact 工具，以及被确认并准入为普通用户输入的操作。这个浏览器包不会另造模型历史通道：`artifact/upsert` 只是 log-only，操作则变成有界 JSON 文本块。

#### Token 影响

渲染 Artifact 不会把源码加入模型请求。只有 Host 已准入的操作会增加有界 JSON 文本。未确认 iframe 提案不会增加输入；放弃本地重试不会移除已准入文本。

#### KV Cache 影响

修订和视图变化不会直接改写模型前缀。只有 Host 准入的操作会按普通缓存规则新增模型可见历史。

##### 浏览器边界

```markdown
Rendering does not make Artifact source model-visible; only a Host-admitted action adds history.
```

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- **远程依赖不可用**——自包含 HTML 必须使用 inline 代码和样式，只能携带允许的本地 data/Blob 资源。
- **提案和重试请求是瞬态**——修订变化会丢弃未确认 iframe 提案。已确认但结果未知的请求在切换修订和视图时保留，卡片或比较所有者卸载、页面刷新时才丢失；这不会撤销 Host 已准入的输入。
- **离开消息流会重新挂载预览**——原生粒子状态由卡片持有，切换布局和源码视图时保留。隐藏的粒子预览会暂停；新修订或卡片卸载会释放该次运行。其他预览重新挂载时仍重置本地状态。
- **后台并排页签保持挂载**——只有激活页签会被绘制，切换页签不会重建预览；但在内联和脱离对话的表面之间切换仍会重新挂载。
- **focus 只在卡片内**——展开呈现不会创建独立对话框，也不会持久化查看偏好。
