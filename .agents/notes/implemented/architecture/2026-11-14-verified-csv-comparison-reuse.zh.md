# Agent Note: 已发送 CSV 对照的验真复用

Status: implemented

[English](2026-11-14-verified-csv-comparison-reuse.md) | 中文

## Problem

原 CSV 不可用时，仍能从消息历史查看已保存的对照。用户粘贴的文字也可能具有同样格式。如果仅凭格式签发新附件凭据，粘贴进来的数值就会以宿主核验过的读数进入后续追问。

## Decision

草稿绑定发送请求时，在接收 Session 和请求 ID 下保存已签发对照的摘要。复用时，宿主用该私有摘要核对确切的历史用户消息，再为同一 Session 中的手动确认签发带有直接来源引用的事实。每次复用只更新这一个引用，对照的来源字段保持固定大小，最初的计算来源继续保留。[Artifact 子系统参考](../../../../docs/subsystems/artifact.zh.md)说明复现和重新附加的行为。

便携对照文件包含已核对的一页及其格式版本。目标宿主校验页面，标记为用户导入的证据，并为该 Session 签发核对凭据。凭据将用户核对的数据绑定到追问准入。对照在确认、发送和复现时都保留导入归属，后续复用引用目标 Session 内的消息。

## Alternatives considered

重新计算依赖原 CSV 仍可读取。在每条追问中增加来源字段会影响共享消息格式。私有摘要由 Artifact 追问组件持有，使用日志中已有的对照。

## Consequences

宿主重启和草稿清理后仍可读取摘要。缺少匹配摘要的旧消息仍可在历史中查看。私有记录只保存摘要，模型继续收到记录中的对照事实。
