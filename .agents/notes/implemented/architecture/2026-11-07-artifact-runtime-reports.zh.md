# Agent Note: Artifact 就绪属于已连接的运行实例

Status: implemented

[English](2026-11-07-artifact-runtime-reports.md) | 中文

## 问题

接受生成源码不能证明浏览器已成功初始化它。按格式显示的共享控件直接发送命令，却不知道两侧程序是否实现或完成操作。持久 ready 标志还会比报告它的运行活得更久，误报后来浏览器会话的状态。

## 决策

SceneCatalog 拥有纯源码能力声明。独立的 [Artifact 运行服务](../../../../packages/artifact/artifact-runtime/README.zh.md)只持有实时双工 Remote 流所附的报告。Session id 是显式资源，不使用 Agent lookup，因此打开报告不会激活冷 Agent。精确修订的模型查询另从 Artifact 服务已准备的 Projection 读取当前源码，将每份运行报告明确标为 Client 上报。

每个物理预览都有新的运行身份。父级接收方检查 frame、Artifact 身份与修订。HTML 在初始化后显式注册已经实现的状态和命令回调；原生预览只在实际 Canvas 绘制后报告。命令携带请求身份，确认回调完成。超时保留副作用未确认的事实，不自动重复操作。

普通 `artifact_runtime` 工具结果记录模型看到的报告快照。用户也可为普通问题绑定一个物理 HTML 预览：提交时冻结最近收到的状态或当前错误，Host 将该声明与自身精确当前源码配对。捕获不重新读取实时注册表，后来的断线不能改变已准入的问题。不新增运行 Session 事件或可恢复的 ready Projection。断开、源码替换、预览释放和服务释放都会结束实时所有权；历史工具结果与问题文本不能证明当前运行。源码创建不等待提交前无法看到它的渲染器。

显式就绪等待是订阅同一批实时报告的有限操作，也覆盖源码提交后的首次附加，但不会留下后台重试。结果区分没有活跃报告、仍在启动的超时与断连，返回全部当前运行，包括同时存在的 ready 与 error 声明。工具按 Agent 轮次限制查询尝试，以及最终结果暴露运行错误后的更新尝试；源码修订不续订预算。进程内计数只约束修复循环，不充当持久授权或自动修复调度器。

## 考虑过的替代方案

**从源码验证成功或 iframe load 推导 ready** 会混淆不同操作并隐藏运行失败。**持久化当前就绪** 会让已关闭的浏览器声称新实例可用。**轮询或心跳租约** 重复既有流生命周期，并引入依赖时钟的所有权。**向提示词注入最新私有报告** 会导致无法重建模型实际读取的内容。

## 影响

没有浏览器就没有实时报告。旧 HTML 仍可预览和提供显式用户意图，但不会获得未声明的共享控制。上报就绪和命令完成不能验证像素、观察或因果结论。源码能力不授予插件可用性或权限。可恢复实验仍使用持久源码与已保存观察，独立于预览生命周期。
