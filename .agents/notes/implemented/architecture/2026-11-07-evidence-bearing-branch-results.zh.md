# Agent Note：分支证据共用不可变结论准入

Status: implemented

[English](2026-11-07-evidence-bearing-branch-results.md) | 中文

## 问题

分支结论可能引用后来改变的实验。回传浏览器文本或仅引用当前 Artifact id，可能附上无关证据。只按结论去重的键还可能在用户更换证据后静默确认旧回流。复制父级提交路径，会让普通与带证据回流在 maintenance、持久化和未知结果处理上产生分歧。

## 决策

Artifact 分支桥接从同一个不可变查询切面读取精确子结论和已保存证据。已保存观察携带完整原始源码和检查点；桥接重算数值，并附上自包含文本。证据由用户选择，不声称助手原推理使用过它。父级 Artifact 和子分支历史保持独立。

两个回流提供方共用 Host 专用的 `session-branch/admission` 操作。它串行化父级写入，对同一结论比较先前内容，只追加新内容，并在确认前 flush。相同内容找回回执；不同内容明确冲突。只有 maintenance 开始前的失败才是 busy。后续失败保留未知结果，需要以不变内容重试。

桥接是独立 Web 插件。主 Artifact 服务保留 headless 依赖，通用 Session Controller 不拥有 Artifact 证据规则。既有 `branch-result` source 和普通文本块保留证据，不另增事件种类或结论账本。

## 考虑过的替代方案

**向 Session Controller 添加 Artifact 选择器**会让通用生命周期代码拥有某一证据领域。桥接负责选择与计算，同时共用真正的提交操作。

**只按结论去重而不比较内容**会在丢弃证据变更的同时报告成功。一条结论只有一次不可变的已接受回流；不同选择会被拒绝，不静默替换或复制。

**只返回跨 Session 指针**需要父级以后再加载子记录，并可能混淆同名 Artifact。自包含证据占用有界消息空间，但能保持各 Session 的对象命名空间独立。

## 影响

预览和取消不产生输入副作用。确认只追加一条父消息，不唤醒模型。未知结果重试会冻结完整选择。大证据可能被完整消息上限拒绝。已回流结论需要新证据时，应产生一条新的子分支结论，不覆盖旧内容，也不自动合并对话。
